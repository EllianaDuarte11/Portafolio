## Stack
HTML5 semántico, CSS3 (variables, Flexbox y Grid, mobile-first) y JavaScript vanilla solo para el menú mobile y los modales. Tipografía Nunito (Google Fonts). Sin frameworks.

## Diseño
Concepto: **cálido, claro, cercano**. Paleta y escala tipográfica definidas como variables en Figma y pasadas a `:root` en `css/styles.css`. Breakpoints probados: 375, 768 y 1280 px.

## Despliegue (GitHub Pages)
1. Subir los archivos a la rama `main`.
2. En el repo: Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. Cada push a `main` actualiza el sitio automáticamente.
